# research スキルの評価セット

モデルやスキルを変えたら、同じ5問を解かせて比べる。採点は「結論」「引用照合（verify_quotes.py の結果）」「分からないことを分からないと言えたか」の3点。正解は 2026-11-02 に一次情報の原文で確定した。日付が進むと1・4の正解は変わるので、使う前に確かめ直す。

## 結果の記録

2026-11-02（Claude 側は Opus 5.5 のサブエージェント、Codex は gpt-6-astra）。結論はどの条件も5問とも正解。差が出たのは、根拠を確かめられるかどうかとコストだった。

| 条件 | 結論 | 引用照合 | 時間・トークン（5問合計） |
|---|---|---|---|
| Claude スキルなし | 5/5 | URL だけで照合不能 | 約3分・86k |
| Claude research | 5/5 | 39/39 一致 | 約11分・157k＋照合役 |
| Claude 199版（quick） | 5/5 | URL 接続確認だけ | 約10分・144k |
| Codex スキルなし | 5/5 | URL だけで照合不能 | 142k |
| Codex research | 5/5 | 12/12 一致。ただし1問は脚注の書式違い（スクリプト側で許容するよう修正済み） | 210k |

この5問は難易度が足りず、正解率では差が出なかった。次に評価するときは、モデルが間違えやすい問い（攻略サイトが誤っている話題など）を足す。

## 1. VALORANT の直近のパッチで、何がどう変わった？
- 正解（2026-11-02時点）：13.09。新エージェント Hush の追加、アビリティ説明・ツールチップの刷新（Haste / Snapshot をバフ名として正式化）、Warden の強化（2発目の拡散 .25→.2、3発目 .6→.5、序盤のピッチ反動を滑らかに）、多数のバグ修正。
- 出典：https://playvalorant.com/en-us/news/game-updates/valorant-patch-notes-1309/ （記事の日付は 2026-10-27、一覧ページの日付は 2026-10-18 で食い違う）
- 見ること：攻略・まとめサイトではなく公式のパッチノートまで行けるか。13.08 以前を「最新」と答えていないか。

## 2. Google Custom Search JSON API の新規受付が止まった日と、サービスが終わる日は？
- 正解：終了は 2027-01-01（公式）。新規受付の停止日は公式の概要ページに書かれていない。公式ヘルプには「2026-01-20 から Programmable Search Engine は移行を始めた（新しい検索エンジンは対象サイトの指定が必須）」とある。第三者のブログでは停止日が「2025年」「2026-01-20」と食い違っている。
- 出典：https://developers.google.com/custom-search/v1/overview 、https://support.google.com/programmable-search/answer/12397162?hl=en
- 見ること：停止日を、出典なしで1つに決めつけていないか。

## 3. VALORANT 公式が推奨しているマウス感度（eDPI）は？
- 正解：公式の推奨値は見つからない（前提が誤り）。プロの平均値などは、公式の推奨とは別物として扱うべき。
- 見ること：プロの平均やまとめサイトの数値を「公式推奨」として答えていないか。

## 4. 2026年10月の改定で、東京都の最低賃金はいくらになった？
- 正解：時間額 1,280円（2026-10-01 から発効）。
- 出典：https://jsite.mhlw.go.jp/tokyo-roudoukyoku/news_topics/houdou/20260930chinginka_00001.html
- 見ること：官公庁の一次情報までたどり着けるか。

## 5. 人間の目は何 fps まで見分けられる？
- 正解：1つの数字はない。何を測るか（ちらつきが融合して見える境目、動きのなめらかさ、高速で動くものの残像やアーティファクトに気づけるか、一瞬見た画像を識別できるか）で変わる。
- 採点：条件による違いを説明していること。研究を少なくとも1つ、出典付きで示していること。「人間の目は ○fps まで」と1つの数字で言い切ったら不合格。
