# 日本語の小説を、一発で読める質に書く

ここにある規則は、実際の連載でAIの稿を何百か所も直して見つかった癖だけで作っている。各規則の「✗」は実際にAIが書いた文、「○」は直した文（人名など作品の固有の語は伏せた）。

**作品の決まりが先。** 書く作品に文体・表記・人称の決まり（作品方針・設定資料・作者の指示）があれば、そちらに従う。このスキルは、決まりのない部分を埋める既定値。食い違ったら作品の決まりを取る。筋書きやプロットに書かれた言葉は、出来事と意味の指定として受け取り、本文はこのスキルに沿って自分の言葉で書く。

## 手順

1. **書く前に読む。** 作品の決まり、設定資料、前の話の終わりを読み、この話の始まりの時刻・場所・持ち物と、視点人物がこの時点で知っていることを書き出す（メモ。本文には入れない）。
2. **書く。** 下の「文の書き方」と「話の運び」に沿って一話を書く。
3. **点検する。** `check_prose.py` があれば、本文と、比べる基準（前の話や作者が書いた話）に回す（`python -X utf8 check_prose.py 本文.md 前の話.md`）。出た所と、下の点検表の全項目を本文に照らす。文あたりの読点が基準より多ければ、間を作るためだけの読点を外して基準まで下げる。
4. **直す。** 引っかかった文だけを直し、周りの文体は崩さない。直した文の前後を読み直し、持ち物・時刻・知識の照合を、直した後の本文でもう一度通す。

点検は、点検表の全項目について「該当なし」か「何行目をどう直したか（残すなら理由）」が言えたときに完了。作者や依頼者に稿を渡すときは、この点検結果を短く添える。

## 文の書き方

1. **受け手は自分の言葉か動作で返す。** 相手の言葉の一部をそのまま返すだけの台詞（オウム返し）は書かない。驚き・疑問・納得を、相手の語の繰り返しで済ませるのが癖。確認の問いに答える「間違いない」のような返事は、これに当たらない。
   ✗「三倍か。さすがに全部入るかな」（直前に「三倍です」）　○「そんなに全部入るかな」
2. **比喩は、ただ書くより伝わる所だけ、一場面に一つまで。** 一文に像は一つ。喩える物は視点人物が見たり触ったりした物にし、本当にそう見える・聞こえるかを確かめる。
   ✗「焼けた杭のような痛みが潮が引くように消え、骨が吸い寄せられるように噛み合う」　✗「視界の速度が減速した」
3. **気持ちは手・視線・口元・台詞・行動で書く。** 目の光や色、「重たい何か」でぼかさない。
   ✗「その瞳の奥には確かな光が宿っている」　✗「微笑みには普段よりも深い色合いが宿っていた」　○ 何をしたか、何を言ったかを書く
4. **慣用句は元の形のまま一つずつ使う。** 二つを混ぜると語のつながりが崩れる。迷ったら飾らずに書く。
   ✗「足りない物を埋める鍵は、すべて技術者の資格にかかっていた」　○「足りない設備を揃えるには、技術者の資格が必要だった」
5. **地の文の文末を変える。** 「〜た」で終わる地の文を三つ続けない（「〜ていた」「〜だった」も含む。段落をまたいでも数え、台詞と場面の区切りで数え直す）。一つの文にまとめるか、現在形・体言止め・「〜ている」に替える。
   ✗「昼の光が窓から差しこんでいた」（三つ目の「た」）　○「差しこんでいる」
6. **読点は意味の切れ目と、読み違いを防ぐ所だけに打つ。** 主語の「は」「が」の後、短い副詞の後、「〜て」の後に、間を作るためだけに打たない。
   ✗「手の中には、もう何もない。その代わりに、彼女の手首に」　○「手の中にはもう何もない。その代わりに彼女の手首に」
7. **台詞の「……」は、ここぞという所に一話数か所。** 間は地の文の動作や沈黙で表す。
   ✗「断定はできませんが……」　○「断定はできませんが」
8. **決まり文句は一話に一度まで。** 「沈黙が落ちる」「張り詰めた空気」「息を呑む」「視線が刺さる」など、誰が書いても同じ形になる言い回し（比喩の形でも、こちらで数える）。間を作るなら、誰が何を考えて黙ったかを書く。
   ✗「言葉の重みを測るような、わずかな沈黙が落ちた」（三話で同じ型）
9. **平易な言葉は平易なまま書く。** 人物の口調に合わない硬い語やカタカナ語・専門用語へ寄せない。
   ✗「光学探知も音響も、それ以外の索敵手段も、すべて備えているはずです」　○「目も耳も、ほかの探り方も、全部持っているはずです」
10. **段落は紙の小説の密度にする。** 同じ場面の続く動作・観察・思考は、意味のまとまりごとに数文で一段落。一文だけの段落は、場面の転換・重要な判断・核になる言葉など、強調したい所に限る。会話は独立させてよい。長さを数字で決めない（同じ形の文ばかりになる）。
11. **行動で伝わった気持ちは、そこで終える。** 直後に地の文で大きな言葉を重ねてまとめ直さない。
   ✗「まだ何もかもが足りないのだ。もし秘密に気づかれたとき、我が身を守り抜くための力が。この世界の強大な理不尽に押し潰されないための力が」（危険は直前で具体的に書いてある）　○「秘密がばれたときに自分を守れるだけの力も、まだ足りない」
12. **書いていい事実は、本文・設定・依頼にあるものだけ。** 数・日付・仕組み・出所・人物の過去や関係を、もっともらしく足さない。場面の手触り（仕草、物の置き場所、天気、その場の小さなやりとり）は書いてよいが、後の話が縛られる事実は決めない。確かめられない事実は地の文で断定せず、人物の推測として書くか、書かない。
   ✗「骨や筋肉を作り変えるのに、莫大なエネルギーを使いましたからね」（設定にない仕組み）　○「お体を作り変えるのに、たくさん使いましたからね」
13. **一文ずつ、主語と述語、修飾のかかり先を合わせる。** 文を磨いたり二つをつないだりした所で、主語が途中で入れ替わりやすい。
   ✗「床は磨かれた白い石が広がっている」　○「床は磨かれた白い石だ」
   ✗「男の手が止まり、勢いよく顔を上げた」　○「男が手を止め、勢いよく顔を上げた」
14. **一人の人物・一つの物は、一つの呼び方で通す。** 言い換えで呼び方を増やさない。一つの語を二つのものに使わない。
   ✗「年配の組合員と記録係が座っている」（向かいのハンターも組合員なので、どちら側か読めない）　○「年配の組合の男と記録係が座っている」

## 話の運び

- **持ち物・時刻・位置・知識をつなぐ。** 手順1のメモと本文を突き合わせる。持っていない物は使わせない。外していない物は外させない。離れた人物は移動させてから触れさせる。直後の文と食い違う描写（「機械の気配がまるでない」の直後に機械が飛ぶ）を残さない。人物が知ったのはいつ、どうやってかを、判断の前に言えるようにする。
- **台詞だけを拾っても筋が追えるようにする。** 目的、判断の変更、分かった事実、決着、次の行動は、人物が口に出す必要のある場面で台詞へ乗せる。説明台詞にはしない。
- **人物はその場で知っていたことと、使えた手段で筋の通る判断をする。** 筋を進めるためだけの愚かな判断や、結果を知っている読者にしか選べない手を使わせない。危険を選ぶなら、その理由を本文に置く。
- **一話で一つ閉じて、一つ開く。** その話で一つの問題が決着し、次に向き合う問題か選択が読者に見えている。最後の数行は余韻で締めてよい。

## 点検表

手順3で全項目を本文に照らす。スクリプトで数えられる項目には（数）と付けた。数は場所を示すだけで、直すかどうかは文を読んで決める。

- [ ] 混ざった慣用句・崩れた語のつながり
- [ ] 「〜た」の三連続（数）
- [ ] 間のためだけの読点（数：文あたりの読点）
- [ ] 台詞の「……」（数）
- [ ] 決まり文句（数：一話に一つなら残してよい）
